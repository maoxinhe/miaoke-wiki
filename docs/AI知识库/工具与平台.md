## 选型参考维度

| 维度 | 说明 |
| --- | --- |
| 能力 | 是否满足任务（推理、多模态、上下文长度） |
| 成本 | 单价、调用量、额度与免费额度 |
| 数据安全 | 数据是否会用于训练、是否存储、是否符合合规 |
| 稳定性 | 可用性、限流、响应速度 |
| 集成性 | 是否有 API / SDK，能否接入现有系统 |

## 使用与接入规范

- 团队统一推荐工具清单，避免成员各自拉群、各建一套。
- 接入业务系统前，走工具准入评估（能力 / 成本 / 安全）。
- 密钥统一管理，禁止硬编码进代码或文档。
