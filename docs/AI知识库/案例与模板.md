# 案例与模板

> 收录团队实际应用场景与可直接复用的模板。每个条目注明实践者与使用时间，便于反馈迭代。

## 应用场景索引

| 场景 | 说明 | 模板 |
| --- | --- | --- |
| 运维排查助手 | 输入报错/现象，输出排查步骤 | [模板示例](#运维排查模板) |
| 文档生成 | 从要点生成规范文档 | [模板示例](#文档生成模板) |
| 代码辅助 | 需求转可运行代码 | [模板示例](#代码辅助模板) |
| 日常问答 | 高频问题快速解答 | 见「基础问题解答」 |

## 运维排查模板

```text
【角色】你是资深运维工程师
【任务】分析下面的故障现象，给出排查步骤
【要求】
- 按「先止血、再定位」排序
- 每步给出可执行命令
- 明确哪些是高风险操作需双人复核
【材料】
<粘贴报错/现象>
```

## 文档生成模板

```text
【角色】你是技术文档工程师
【任务】根据要点生成一份<文档类型>（如操作手册/FAQ）
【要求】
- 结构：概述→步骤→常见问题→注意事项
- 语言正式、条理清晰，面向<受众>
【要点】
<粘贴要点>
```

## 代码辅助模板

```text
【角色】你是<技术栈>高级工程师
【任务】实现<功能需求>
【要求】
- 输出可直接运行的代码
- 处理边界情况与错误
- 附简要说明
【约束】
<技术栈 / 依赖 / 编码规范>
```
