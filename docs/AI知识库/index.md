# AI 知识库

沉淀团队在 AI 应用方面的知识、工具、经验与规范，供全员学习与复用。目标是：**把 AI 用起来、用对、用得合规**。

## 板块导航

| 板块 | 内容 |
| --- | --- |
| [入门与概念](./入门与概念) | AI 基础概念、常见术语，帮助快速建立认知 |
| [工具与平台](./工具与平台) | 团队可用的 AI 工具、模型、平台的选型与入口 |
| [提示词工程](./提示词工程) | 如何写出高质量提示词，模板与技巧 |
| [API 与集成](./API与集成) | 接入大模型 API、开发集成的实践 |
| [案例与模板](./案例与模板) | 团队实际应用案例与可直接复用的模板 |
| [最佳实践与合规](./最佳实践与合规) | 使用规范、数据安全与合规红线 |

## 使用建议

1. **先学概念，再谈应用**：新人从「入门与概念」开始。
2. **模板优先**：需要写提示词时，先到「案例与模板」找现成方案。
3. **合规第一**：涉及数据与敏感信息时，先看「最佳实践与合规」。

## 维护约定

- 工具、模型、平台信息时效性强，标注使用时间与来源。
- 涉及 API 密钥、内网服务等敏感信息一律脱敏。
- 每个条目注明实践者 / 作者，便于追责与反馈。
