# 入门与概念

> 用最直白的语言讲清 AI 常用概念，帮助团队成员快速建立认知。

## 核心概念

| 术语 | 通俗解释 |
| --- | --- |
| 大语言模型（LLM） | 通过海量文本训练、能理解并生成自然语言的模型，如 GPT、智谱等系列 |
| 提示词（Prompt） | 你给模型的指令/问题，输入质量直接决定输出质量 |
| Token | 模型处理文本的基本单位，大致可理解为「词/字符」，计费与限制常按它计算 |
| 上下文窗口 | 模型一次能「记住」的输入长度上限，超过会被截断 |
| 多模态 | 模型能同时处理文字、图片、音频、视频等 |
| RAG（检索增强生成） | 先检索相关知识，再交给模型回答，让回答更准确、可溯源 |
| 微调（Fine-tune） | 用业务数据进一步训练模型，使其更贴合特定任务 |
| 幻觉 | 模型「一本正经地编造」不存在的答案，需人工核验 |

## 能力边界与注意事项

- **能做**：信息整理、文案起草、代码辅助、问答、翻译、总结、思路梳理。
- **不能替代**：对事实与数据的最终核验、专业决策（法律、医疗、财务等）、保密数据处理。
- 模型回答可能出错或有偏见，**关键内容务必人工复核**。

## 常见误区

| 误区 | 正确认知 |
| --- | --- |
| 把模型当搜索引擎 | 模型会「编」，重要事实要溯源验证 |
| 一次问出完美答案 | 好答案靠多轮追问、拆解问题 |
| 随意上传机密 | 需先确认工具的隐私策略与合规要求 |

## 推荐学习路径

1. 看完本文，建立基本概念。
2. 阅读「提示词工程」，学习提问技巧。
3. 到「案例与模板」找一个与自己工作相关的场景练手。
