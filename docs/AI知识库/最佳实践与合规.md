# 最佳实践与合规

> 团队使用 AI 的底线与规范。**合规优先，宁可不用，不可违规。**

## 数据分级与使用

| 数据级别 | 说明 | 是否可交给 AI 工具 |
| --- | --- | --- |
| 公开 | 无敏感信息 | 可以 |
| 内部 | 内部非敏感业务信息 | 需确认工具隐私策略后使用 |
| 敏感 | 客户隐私、财务、密钥、个人身份信息 | **默认禁止**，需专项审批 |

::: danger 红线
- 禁止将客户隐私、公司密钥、内网地址、财务数据等敏感信息输入未经批准的 AI 工具。
- 使用第三方 AI 工具前，先确认其数据是否会被用于训练、是否留存。
:::

## 使用规范

| 场景 | 要求 |
| --- | --- |
| 事实与数据 | 关键结论必须人工核验、溯源，防止幻觉 |
| 决策类内容 | 法律、医疗、财务等专业决策不得仅凭 AI 输出 |
| 对外输出 | 对外文案需人工审阅，避免错误与不实表述 |
| 代码 | 生成的代码需审查安全与正确性后再合入 |

## 工具准入流程

1. 团队发起工具试用与评估（能力 / 成本 / 安全）。
2. 填写合规评估（数据处理方式、留存、归属）。
3. 通过后纳入推荐清单，统一密钥管理。
4. 定期复核，退出不合规或不再使用的工具。

## 常见合规问题

| 问题 | 建议 |
| --- | --- |
| 可以把公司数据喂给免费 AI 吗？ | 默认不行，先确认隐私策略与数据分级 |
| 模型生成的代码能直接用吗？ | 审查后再用，注意开源许可与安全性 |
| 如何防止敏感信息被误发？ | 教育 + 工具白名单 + 输入审计（如必要） |
