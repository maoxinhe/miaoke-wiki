# cmy-patch · 使用指南与常见问题

> 面向使用「cmy-patch（梦之韵整合包更新系统）」的团队成员与玩家端用户。

## 一、如何访问 / 登录

- **管理后台**：`cd admin-ui && npm run dev`，浏览器打开本地地址（默认数据源 `http://127.0.0.1:18990`，需先启动 serve）。
- **玩家端**：启动器 Pre-launch 触发 cmy-patch-player，经 PermitGate 授权后放行。

## 二、常用功能与操作步骤

1. **发布新版本**：改好源目录文件 → 控制台「发布新版本」→ 填写版本号/变更日志 → 预览扫描变更 → 确认发布。
2. **回滚**：版本发布页 → 目标版本行「回滚」→ 确认。
3. **维护规则**：维护规则页 → 增删预设规则（REQUIRED/SYNC/INITIAL/DEFAULT_CONFIG）/ 可选组 / 清理目录 → 保存。
4. **备份**：备份恢复页 →「立即备份」。
5. **部署**：分发部署页 → 填 S3/WebDAV 配置 → 保存 →「立即部署」。

## 三、权限说明

- **管理端**（服主/运营）：发布、回滚、规则、部署、备份全量操作。
- **玩家端**：模组启停、可选组开关、自行管理标记、本地变更确认（无管理权限）。

## 四、使用中的注意事项与限制

- admin-ui 未连后端时仅展示演示数据，操作不落库；页面顶部有绿/琥珀连接徽章。
- Backup「恢复」按钮暂不可用（后端待实现）。
- player-ui 的 Rust/Tauri 侧工具链未验证（待核对），无 Tauri 环境自动降级演示模式。

## 五、常见问题（FAQ）

### Q1：admin-ui 显示「未连接后端·演示数据」？
**原因**：serve 未启动/端口被占。
**解决**：启动 serve，`lsof -ti:18990` 确认监听正常。

### Q2：`/api/scan` 返回 400「Unable to scan directory」？
**原因**：sourceDir 不存在或被清理。
**解决**：核对启动参数，重建源目录。

### Q3：publish 命令报用法错误？
**原因**：参数顺序不对。
**解决**：`publish <projectId> <sourceDir> <outputDir> <版本号> [changelog]`。

### Q4：玩家端更新后校验失败？
**原因**：清单签名不匹配或对象未上传完整。
**解决**：确认私钥未更换、objects 全部上传、公钥与发布端一致。

### Q5：部署后玩家仍下载旧版本？
**原因**：配置未保存或目标不可达。
**解决**：先 PUT `/api/deploy` 保存，再 POST 部署，检查 S3/WebDAV 连通性。

### Q6：端口 18990 被占用？
**原因**：旧 serve 进程残留。
**解决**：`kill $(lsof -ti:18990)` 后重启。

### Q7：回滚后玩家没反应？
**原因**：回滚生成新序列号，需玩家端下次检查更新。
**解决**：等待玩家端下一次启动检查，确认其内置公钥正确。

### Q8：139 网盘经 Alist 下载慢/失败？
**原因**：私有 API 风控或直链过期。
**解决**：仅作备份归档，重新生成直链，勿作热下载主源。
