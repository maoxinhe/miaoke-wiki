# MC Web 网页版 Minecraft · 使用指南与常见问题

> 面向使用「MC Web（mc.web.camzy.tech）」的团队成员。遇到问题先看本页 FAQ。

## 一、访问

- 浏览器打开 `https://mc.web.camzy.tech/`（需支持 WebGL，建议 Chrome/Edge/Firefox）。

## 二、操作

1. 打开 → 喵科大加载屏 → 倒计时或点「点击进入」→ 主菜单 → 新建/进入世界游玩。

## 三、权限

- 站点公开可访问；仅负责人可改客户端（GitHub 写权限）。

## 四、限制

- 固定 1.12.2 版本；联机未接入；存档随浏览器，不跨设备。

## 五、常见问题（FAQ）

### Q1：打开是空白 / 提示人机验证？
**原因**：腾讯 EdgeOne WAF 拦截。
**解决**：勾选复选框完成验证，或更换网络/浏览器。

### Q2：提示 WebGL is not supported？
**原因**：设备禁用了 GPU 渲染。
**解决**：换支持 WebGL 的 Chrome/Edge/Firefox。

### Q3：看到旧加载屏（"This file is from..."）？
**原因**：浏览器缓存旧版本。
**解决**：强制刷新 / 清缓存。

### Q4：进游戏是英文？
**原因**：1.12.2 客户端默认英文。
**解决**：在游戏内「Options」改语言。

### Q5：进度条卡住 / 加载慢？
**原因**：20MB 首次加载 + 网络慢。
**解决**：等待，或换网络。

### Q6：想玩 1.21 / 更高版本？
**原因**：客户端固定 1.12.2。
**解决**：需另行部署现代 fork 与服务器（未实施）。

### Q7：存档不见了？
**原因**：存档在浏览器 IndexedDB。
**解决**：勿清浏览器数据；换设备存档不通用。

### Q8：想改加载屏/文案？
**原因**：需修改客户端源码区。
**解决**：改 `index.html` 中 `launch_countdown_screen` 区块 → push 自动重建。

### Q9：域名打不开？
**原因**：DNS/CNAME 未生效或指向错误。
**解决**：检查 `mc.web` 是否 CNAME 到 `maoxinhe.github.io`。
