# 网络与连接

> 涉及内网地址、VPN、代理等信息请脱敏编写，敏感细节通过安全渠道交付。

## 无法上网怎么办？

| 排查项 | 检查方式 |
| --- | --- |
| 物理连接 | 网线 / Wi-Fi 是否正常连接 |
| 是否被代理/防火墙拦截 | 检查系统代理设置、公司安全软件 |
| DNS 是否异常 | 尝试更换 DNS 或用 IP 访问验证 |
| 网络是否中断 | 联系网络负责人确认链路状态 |

## 如何远程访问 / 连接内网？

- 通过 VPN / 远程桌面等方式访问内网资源（入口与配置方式待补充）。
- 连接失败时检查：VPN 客户端状态、账号是否有效、是否被策略限制。

## 域名 / DNS 问题

- 站点无法解析：检查本地 DNS、缓存刷新（`ipconfig /flushdns` 或 `systemd-resolve --flush-caches`）。
- 域名未生效：确认解析记录已配置并等待生效。

## 端口被占用

- 排查：`netstat -ano` / `ss -tlnp` 查看占用进程。
- 处理：结束占用进程或更改应用监听端口。
