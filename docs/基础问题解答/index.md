# 基础问题解答

面向团队成员的常见问题汇总。**遇到问题先在这里检索**，命中后按步骤操作；未命中再向负责人求助，并欢迎把新问题补充进来。

## 分类导航

| 分类 | 覆盖内容 |
| --- | --- |
| [账号与权限](./账号与权限) | 登录、账号开通、权限申请、密码重置 |
| [软件与工具](./软件与工具) | 常用软件安装、配置、协作工具 |
| [网络与连接](./网络与连接) | 联网、远程访问、内网/VPN |
| [常见报错](./常见报错) | 高频报错的含义与处理 |
| [其他问题](./其他问题) | 未归类的日常问题 |

## 使用方式

- 用右上角**搜索框**输入关键词（如「VPN」「账号」）快速定位。
- 每个问题采用「问题 → 原因 → 解决步骤」的结构。
- 提交新问题时，请附带具体现象、复现步骤与环境，便于他人复用。

## 维护约定

- 优先补充**高频、有明确解法**的问题，避免主观争议内容。
- 涉及公司凭据、内部地址的内容脱敏后编写。
- 每个条目标注「最后更新」，长期未更新可标记为待核对。
