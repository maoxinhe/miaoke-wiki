# 常见报错

> 按「报错信息 → 原因 → 解决」整理高频错误。遇到不在清单中的报错，请补充进来。

## 报错对照表

| 报错 / 现象 | 常见原因 | 解决办法 |
| --- | --- | --- |
| `连接超时 / timeout` | 网络不通 / 目标服务未启动 / 防火墙拦截 | 检查连通性、服务状态、防火墙规则 |
| `Permission denied` | 权限不足 | 使用有权限的账号，或申请相应权限 |
| `端口被占用` | 端口冲突 | 见「网络与连接」端口占用章节 |
| `磁盘空间不足` | 磁盘写满 | 见「故障排查」磁盘章节，清理或扩容 |
| `数据库连接失败` | 连接串错误 / 连接数打满 / 服务宕机 | 核对连接串，查连接数与服务状态 |
| `证书不受信任` | 证书过期 / 未安装 | 更新证书或信任证书 |
| 软件闪退 / 崩溃 | 依赖缺失 / 配置损坏 | 重装或修复配置 |

## 如何提交一个新的报错条目

1. 写明**完整报错原文**（截图或文本）。
2. 描述**复现步骤**与环境（系统版本、软件版本）。
3. 说明已尝试的排查动作与结果。
4. 提交 PR 补充到本表，或联系负责人协助沉淀。
