# 喵科大起始页 · 使用指南与常见问题

> 面向使用「喵科大起始页」（Miaoke New Tab）的团队成员与访问者。遇到问题先看本页 FAQ。

## 一、访问 / 登录

- 浏览器直接打开 `https://hao.camzy.tech/`，**无需登录**（公开访问）。

## 二、常用功能

1. **快捷导航**：点击右下角「添加链接」/「设置」→ 快速导航 → 添加；图标自动抓取站点 favicon。
2. **背景**：设置 → 背景 → 更换；或右下角「更换背景」按钮。
3. **主题**：设置 → 外观 → 深色/浅色、莫奈取色、主题色。
4. **书签**：右下角「书签」按钮管理。
5. **搜索**：顶部搜索框直达。

## 三、权限

- **访问者**：浏览、本地自定义设置。
- **维护者**（Camzy 等）：改源码、构建部署、DNS/CDN 配置。

## 四、注意事项与限制

- 手机端无 hover，按钮下方有文字标签；个性化设置在本地浏览器，换设备需 WebDAV 同步。

## 五、常见问题（FAQ）

### Q1：设置面板打开没字？
**原因**：网页版跳过设置初始化，i18n 未加载。
**解决**：web-polyfill.js 动态 `import` i18n chunk 触发 `initI18n()`；改后需重新构建并更新 chunk 路径。

### Q2：背景或快捷链接空白？
**原因**：网页版壁纸接口/扩展 API 失效。
**解决**：web-polyfill.js 兜底注入壁纸 + 强制快捷链接可见。

### Q3：右下角按钮没字？
**原因**：原版为纯图标。
**解决**：polyfill 给按钮补文字标签（设置/书签/下载背景）。

### Q4：浏览器提示不安全？
**原因**：专属证书未签发，先用兜底证书。
**解决**：EdgeOne 开 eofreecert，等 1~2h 签发，`subject` 变为 `CN=hao.camzy.tech`。

### Q5：首页弹「安全验证」？
**原因**：EdgeOne 人机验证拦截异常流量。
**解决**：真实浏览器正常通过；自动化/无头会被拦。

### Q6：出现「喵科大起始页启动失败」？
**原因**：恢复被 patch 的设置初始化会触发兜底页。
**解决**：保持跳过 `Q().init()`，靠 polyfill 兜底，勿回改。

### Q7：改完代码线上没变化？
**原因**：EdgeOne 缓存未清或 chunk 名变更未重 patch。
**解决**：`CreatePurgeTask` 全站清缓存 + 重跑补丁脚本。

### Q8：图标显示灰色占位？
**原因**：子站无真实 favicon。
**解决**：给对应子站配置 favicon 即可。
