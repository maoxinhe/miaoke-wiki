## 软件安装常见问题

### 安装失败 / 提示权限不足
- 检查是否有管理员权限；用普通账号安装到用户目录。
- 核对系统版本是否满足要求，是否有残留旧版本冲突。
- 查看具体报错信息，按「常见报错」章节对照。

### 软件无法启动 / 闪退
- 检查是否缺少运行依赖（如运行库、驱动）。
- 查看日志定位原因（常见于配置文件损坏或端口冲突）。
- 尝试以管理员身份运行或重装。

### 版本不一致
- 统一工具版本，避免跨成员协作时因版本差异出问题。
- 重要工具由团队统一发布版本与安装包，禁止随意用最新版。
