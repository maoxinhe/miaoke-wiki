# 微办公系统 · 使用指南与常见问题

> 面向使用「微办公系统」的团队成员。遇到问题先看本页 FAQ，未命中再联系管理员。

## 一、如何访问 / 登录

- **办公后台**：`https://office.camzy.tech/app.html`（独立账号登录）
- **对外问卷入口**：`https://office.camzy.tech/s/p.html`
- 管理员初始账号在私有配置中（首次登录后请立即改密码）。

## 二、常用功能与操作步骤

1. **文档管理**：上传文档（可设公开/内部）→ 按文件夹归类 → 搜索 → 预览 → 移入文件夹 → 删除（进回收站，可恢复）。
2. **在线表格**：新建表格 → 多 Sheet 切换 → 单元格支持公式（`=SUM(A1:A3)` 等）→ 点击列头排序 → 导出 CSV/Excel。
3. **问卷/调查**：新建问卷 → 添加题目 → 开放后对外页可填 → 「统计」按钮看分布条形图与文字回答汇总。
4. **办公协作**：发布公告 → 建待办 → 发起审批（请假/报销/其他）→ 日历排日程 → 任务看板建卡并跨列移动（‹ ›）。
5. **通讯录**：查看成员卡片，按姓名/部门/账号搜索。
6. **个人中心**（右上角）：自助改资料（姓名/部门/手机）与改密码。

## 三、权限说明

- **管理员**：全部功能 + 员工管理。
- **普通员工**：文档/表格/问卷/协作/看板/通讯录，改自己资料与密码；问卷与公开文档对外只读、外部无账号填写问卷。

## 四、注意事项与限制

- 看板卡片跨列为按钮式移动（非拖拽）。
- 手机端已适配，但表格/看板建议横屏体验更佳。

## 五、常见问题（FAQ）

### Q1：登录后一直跳回登录页？
**原因**：会话失效 / Token 过期。
**解决**：重新登录，必要时强制刷新（Ctrl+F5）。

### Q2：删除文档找不到了？
**原因**：删除是软删除，进回收站。
**解决**：文档区点「回收站」→ 恢复或彻底删除。

### Q3：表格公式不生效？
**原因**：需以 `=` 开头且引用单元格范围。
**解决**：写成如 `=SUM(A1:A3)`，支持 SUM/AVG/COUNT/MAX/MIN。

### Q4：问卷外部人员怎么填？
**原因**：问卷需先「开放」。
**解决**：在问卷列表点「开放」，再对外提供 `/s/p.html` 入口。

### Q5：看不到某文档？
**原因**：文档为「内部」可见性，或已移入回收站。
**解决**：需登录；若属内部权限，联系管理员。

### Q6：改了密码忘了？
**原因**：无找回通道。
**解决**：联系管理员重置（管理员账号数据在私有配置）。

### Q7：服务异常打不开？
**原因**：进程未跑或内存不足。
**解决**：运维按「运维手册·微办公系统」用 `pm2 restart office` 并查日志。
