# 喵科大企业邮 · 使用指南与常见问题

> 面向使用「喵科大企业邮」（`@camzy.tech` 邮箱）的团队成员。遇到问题先看本页 FAQ。

## 一、访问 / 登录

1. 打开 `mail.camzy.tech`（官网）→ 点「登录邮箱」进入 `mail.camzy.tech/login`；也可直接访问 `/login`。

## 二、登录方式

1. **邮箱账号 + 密码**：直接登录。
2. **SSO 授权登录**：点「使用 SSO 授权登录」，经 `sso.camzy.uno` 免密进入。

## 三、配置客户端

- **服务器**：`mail3.serv00.com`，IMAP 993 / SMTP 465，全部开启 SSL。
- 兼容 Outlook、Thunderbird、Foxmail、手机原生邮件。

## 四、权限

- `admin@` / `postmaster@` 为管理员；普通账号（如 `catkinr@`）仅收发自用邮箱。

## 五、使用注意

- 登录框邮箱输入**不接受空格**（含尾部空格）。
- 密码含 `%` / `#` 时粘贴易丢字符，请逐字核对。

## 六、常见问题（FAQ）

### Q：访问 mail.camzy.tech 仍是旧 Webmail？
**原因**：EdgeOne 缓存旧页面。
**解决**：EdgeOne 控制台刷新缓存，客户端强制刷新。

### Q：登录报 Access Denied / Disallowed Sec-Fetch？
**原因**：SnappyMail 拦跨站导航。
**解决**：`[security] secfetch_allow` 已配置 `mode=navigate,dest=document,site=cross-site` 放行。

### Q：SSO 提示「尚未配置 SSO 密码」？
**原因**：该邮箱未写入 `ssopass.json`。
**解决**：管理员在密码库中为 `xxx@camzy.tech` 配置密码。

### Q：输入邮箱提示「请与所请求的格式保持一致」？
**原因**：输入框 pattern 拒空格。
**解决**：删除地址中任何空格再提交。

### Q：收不到信 / 发不出？
**原因**：MX/SPF/DKIM 或端口异常。
**解决**：核对 DNS 记录与 993/465 端口是否可达。

### Q：客户端提示证书过期？
**原因**：TrustAsia 一年有效期。
**解决**：腾讯云续期后重新安装并刷新 CDN 缓存。

### Q：SSO 授权后进不去邮箱？
**原因**：OIDC client_secret 变更或回调被改。
**解决**：核对 `/sso/callback.php` 的 redirect 与 client_secret（占位）。

### Q：空间不足？
**原因**：默认 1G/账号。
**解决**：联系管理员扩容或清理邮件。
