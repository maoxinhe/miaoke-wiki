# 账号与权限

## 如何开通团队账号？

新成员加入时，由管理员按流程创建账号（统一账号体系），并分配默认角色与权限。

- **申请入口**：联系管理员（或走团队审批流程，待补充）。
- **开通周期**：建议在入职当天完成，避免影响工作。
- **所需信息**：姓名、岗位、邮箱 / 手机号（用于绑定）。

## 如何申请某项权限？

1. 明确需要的权限与用途（写清楚「为什么需要」）。
2. 走审批流程（待补充），由对应负责人审批。
3. 权限开通后做最小授权，并登记。

::: tip 原则
权限遵循**最小化**原则：够用即可。离职 / 调岗时权限及时回收。
:::

## 密码 / 登录凭证遗忘或过期怎么办？

- 通过统一登录页的「忘记密码」自助重置（如已接入 SSO）。
- 无法自助时，联系管理员重置，并按提示设置新密码。
- 建议启用二次验证（MFA），提升账号安全。

## 收不到验证码 / 登录失败？

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 收不到验证码 | 手机号未绑定 / 短信拦截 | 核对绑定信息，检查拦截，重发 |
| 一直登录失败 | 账号被锁定 / 密码错误 | 等待解锁或联系管理员重置 |
| 提示无权限 | 角色不含所需权限 | 走权限申请流程 |

## 离职 / 调岗流程

- 通知管理员回收账号与权限。
- 移交名下文档与资产。
- 轮换可能被该成员掌握的共享密钥。
