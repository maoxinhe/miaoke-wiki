# 喵科大EC · 使用指南与常见问题

> 面向使用「喵科大EC 便携浏览器」的团队成员。遇到问题先看本页 FAQ。

## 一、如何访问 / 登录

1. 从下载页获取对应平台安装包（Windows `.exe` / Linux `.AppImage`）。
2. Windows：双击 exe 即可运行；Linux：`chmod +x 文件.AppImage && ./文件.AppImage`。
3. 点击工具栏云朵图标 → 注册账号 → 登录。

## 二、常用功能

- **地址栏**：输入网址直接访问，输入关键词自动用必应搜索。
- **主页**：点击工具栏房子图标回到品牌主页。
- **云端同步**：登录后自动拉取书签、主页、主题配置。
- **WARP 加密**：点击工具栏盾牌图标 → 连接 WARP（需先安装 Cloudflare WARP 客户端并开启代理模式）。
- **便携模式**：启动时加 `--portable` 参数，用户数据写入程序旁 `data/` 目录。

## 三、权限说明

| 角色 | 权限 |
| --- | --- |
| 普通用户 | 注册/登录、读写自己的云端配置、上报版本 |
| 管理员 | 以上全部 + 更新云端版本号（需 Admin Key） |

## 四、注意事项与限制

- 便携模式下不要删除程序旁的 `data/` 目录，否则丢失本地配置。
- WARP 代理依赖本地 WARP 客户端（`127.0.0.1:40000`），未安装时按钮不可用。
- 浏览器内置 Cloudflare DoH（1.1.1.1），无需额外配置。
- 当前为单标签页设计，多标签功能待后续版本。

## 五、常见问题（FAQ）

### Q1：浏览器启动后白屏/闪退？
**原因**：可能是显卡驱动不兼容。
**解决**：尝试加 `--disable-gpu` 参数启动，或更新显卡驱动。

### Q2：云端登录提示「网络错误」？
**原因**：无法访问 `api.mcy.camzy.uno`。
**解决**：检查网络是否能访问 Cloudflare；公司内网可能拦截，切换网络重试。

### Q3：WARP 按钮灰色/点不了？
**原因**：未检测到本地 WARP 客户端。
**解决**：安装 Cloudflare WARP 客户端，执行 `warp-cli set-mode proxy` 开启本地代理后重试。

### Q4：便携模式下数据存在哪里？
**原因**：便携模式重定向了 userData。
**解决**：数据在程序同级的 `data/` 目录，整个文件夹拷走即完成迁移。

### Q5：如何更新到最新版？
**原因**：版本检测在启动时自动执行。
**解决**：启动时若有更新会提示，按提示下载新版替换旧文件即可；便携模式直接替换 exe，`data/` 目录保留。

### Q6：Linux AppImage 双击没反应？
**原因**：缺少执行权限。
**解决**：终端执行 `chmod +x 喵科大EC-*.AppImage` 后再运行。

### Q7：忘记云端账号密码？
**原因**：当前未实现密码找回功能。
**解决**：联系管理员重置，或重新注册账号（旧账号配置无法迁移）。

### Q8：官网下载链接 404？
**原因**：Release 资产可能未上传完成。
**解决**：联系运维确认 GitHub Actions 构建状态，或从 Actions → Artifacts 下载。
