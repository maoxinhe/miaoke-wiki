# 参与贡献

欢迎团队成员共同维护「喵科大服务站」。本站内容以 Markdown 存放在 GitHub 私有仓库，任何授权成员都可提交修改。

## 内容组织

```
docs/
├── index.md               # 首页
├── 运维手册/              # 运维手册板块
├── 基础问题解答/          # FAQ 板块
└── AI知识库/              # AI 知识库板块
```

- 新增文章：在对应板块目录下新建 `.md` 文件。
- 修改文章：编辑对应 `.md` 文件。
- 文件名使用中文，便于阅读；侧边栏与导航在 `docs/.vitepress/config.mjs` 中配置。

## 修改流程

### 方式一：GitHub 网页直接编辑（适合小改动）

1. 打开对应 `.md` 文件，点击「编辑此页」或右上角 ✎ 图标。
2. 修改内容。
3. 提交时选择「Create a new branch and start a pull request」，填写修改说明。
4. 发起 Pull Request，评审通过后合并。

### 方式二：本地编辑（适合批量改动）

```bash
git clone git@github.com:<你的组织>/miaoke-wiki.git
cd miaoke-wiki
npm install          # 首次安装依赖
npm run docs:dev     # 本地预览，浏览器打开提示的地址
# 编辑 docs/ 下的 markdown，保存后页面热更新
npm run docs:build   # 本地构建检查
```

## 内容规范

- 遵循每个板块首页的「维护约定」。
- 涉及命令、参数、地址时**先验证再写入**。
- 敏感信息（密钥、内网地址、个人隐私）一律脱敏，禁止明文写入。
- 保持「问题→原因→解决」「概述→步骤→常见问题」等清晰结构。

## 评审与发布

- 合并到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。
- 变更保留在 Git 历史中，可随时回退。
- 页面底部「编辑此页」链接指向仓库对应文件，方便随手完善。
