## 本站定位

「喵科大服务站」是团队的**统一运维与知识协作平台**，把散落在聊天记录、个人笔记里的经验固化为可持续维护的文档。所有内容以 Markdown 编写，存放在 GitHub 仓库，通过多人协作维护、自动发布到本站。

- **多人协作**：任何授权成员都能提交修改，经评审后合并，变更全程留痕。
- **自动发布**：内容推送到主分支后，站点自动重新构建并发布。
- **可追溯**：每一页都有「编辑此页」入口，历史版本可随时回退。

## 维护约定

1. 内容以事实为准，涉及命令、参数、地址时必须先验证再写入。
2. 涉及账号、密钥、内网地址等敏感信息，一律写入仓库的私有配置文件或通过安全渠道交付，**不得明文写进本站页面**。
3. 每份文档标注责任人与最后更新日期，便于后续跟进。
