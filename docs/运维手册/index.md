# 运维手册

本文档为「喵科大服务站」的运维操作规范，按项目组织，供团队运维与开发成员查阅。所有操作应确认环境影响、按环境区分生产/测试，涉及生产环境的高风险操作需双人复核。

## 项目文档

| 项目 | 说明 | 负责人 |
| --- | --- | --- |
| [微办公系统](./微办公系统) | 内部办公协作平台（office.camzy.tech） | CAMZY |
| [喵科大EC](./喵科大EC) | 便携浏览器 + 云端同步（api.mcy.camzy.uno） | 猫星河 |

> 其余项目的运维知识按统一格式整理后持续补充到本板块。

## 使用建议

1. **先查后问**：遇到问题先在本手册检索对应项目，再升级求助。
2. **按环境区分**：所有命令、参数需区分 `生产` / `测试` 环境，默认禁止在生产环境直接执行未经核对的命令。
3. **变更留痕**：重要操作记录时间、操作人、变更内容，便于回溯。

## 维护约定

- 内容以事实为准，涉及命令、参数、地址时必须先验证再写入。
- 涉及账号、密钥、内网地址等敏感信息，一律存私有配置或通过安全渠道交付，**不得明文写进本站页面**。
- 每个项目文档标注负责人与最后更新日期，便于后续跟进。
