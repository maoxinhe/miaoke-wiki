# 网络与安全

> 安全是底线。本节规范网络拓扑、访问控制与密钥管理。**真实 IP、域名、密钥不写入本站公开页面**。

## 网络拓扑

| 网段 | 用途 | 访问边界 | 备注 |
| --- | --- | --- | --- |
| （待补充） | 生产环境 | 仅内部/白名单 | — |
| （待补充） | 测试环境 | 内部 | — |
| （待补充） | 管理网络 | 仅运维 | 高权限 |

## 访问控制规范

- 默认**最小权限**：只开放业务所需端口，管理端口仅对白名单 IP 开放。
- 对外服务统一通过负载均衡 / 网关，隐藏内部结构。
- SSH 等管理通道使用密钥认证，禁用密码登录（或启用强口令 + 二次认证）。

## 密钥与凭据管理

| 类型 | 存放位置 | 轮换频率 | 负责人 |
| --- | --- | --- | --- |
| 服务器 SSH 密钥 | 私有配置 | 成员变更时 | （待指定） |
| API Token / 密钥 | 密码管理工具 / 私有配置 | 定期 | （待指定） |
| 数据库凭据 | 私有配置 | 定期 | （待指定） |

::: danger 红线
- 严禁将密钥、Token、内网地址明文提交到 Git 仓库或写入本站文档。
- 发现凭据泄露时立即轮换，并排查泄露范围。
:::

## 安全事件响应

1. 发现异常（异常登录、可疑流量、告警）→ 立即隔离受影响系统。
2. 收集日志与时间线。
3. 通知安全负责人，按预案处置。
4. 事后复盘，更新防护策略。
