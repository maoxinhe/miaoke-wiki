## 数据库连接规范

- 应用侧使用专用账号，权限按需最小化，禁止应用使用管理员账号。
- 生产库的 DDL 变更需审批，先评审后执行，避免锁表影响线上。
- 大批量操作（删除 / 更新）必须先在测试环境验证并备份。
