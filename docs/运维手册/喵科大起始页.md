# 喵科大起始页 · 运维知识

> 本文档为「喵科大起始页（Miaoke New Tab）」的运维与部署规范，归档于团队 wiki「运维手册」板块。**所有密钥、Token 一律使用占位符，真实值存放于私有配置**。

## 一、项目概览

### 项目信息

- **项目名**：喵科大起始页（Miaoke New Tab）
- **用途**：团队/社区自定义浏览器新标签页（搜索、快捷导航、壁纸、主题、书签）。
- **一句话**：品牌化魔改的开源新标签页，部署于 GitHub Pages + 腾讯云 EdgeOne。

### 技术栈 / 依赖

- **前端**：Vue 3 + Vite + WXT（扩展框架）、Element Plus、SCSS、i18next。
- **托管**：GitHub Pages（仓库 `maoxinhe/miaoke-start`，产物即站根）。
- **加速/CDN**：腾讯云 EdgeOne（服务 `teo` / `2022-09-01`，区域 `ap-guangzhou`）。
- **外部服务**：Bing 壁纸（网页版 mock 替代）、一言/今日诗词、WebDAV 同步。

### 主要负责人

- **运维**：喵科大 Camzy（站内昵称）；紧急联系见「安全红线」。

## 二、运维注意事项

### 1. 运行环境

- **访问**：`https://hao.camzy.tech/`（443，GitHub Pages 回源，EdgeOne 加速）。
- **DNS**：`hao` CNAME → EdgeOne CNAME（`hao.camzy.tech.eo.dnse0.com.`）。
- **本地预览**：`127.0.0.1:8123`。
- **凭据清单**（一律存私有配置，禁止明文入库）：
  - GitHub Personal Token：`<GitHub Token>`
  - 腾讯云 SecretId / SecretKey：`<Tencent SecretId>` / `<Tencent SecretKey>`
  - DNSPod / EdgeOne API Token：`<API Token>`

### 2. 启动与停止

静态站点无后台进程，无需启停。本地开发：

```bash
# 本地预览构建产物
cd <产物目录> && python3 -m http.server 8123 --bind 127.0.0.1
# 启动开发模式（改源码时）
npx wxt dev
```

### 3. 部署与发布

```bash
# 1) 改源码后构建
cd <源码目录> && npx wxt build        # 约 30s，产物在 .output/chrome-mv3
# 2) 必跑补丁（每次 build 后 chunk 名变，需重新 patch）
node <lemon-render>/apply_mock_patch.mjs
# 3) 重建网页化文件：复制 newtab.html→index.html、注入 web-polyfill.js、恢复 CNAME/.nojekyll
# 4) 推送产物仓库（maoxinhe/miaoke-start）
cd <产物目录> && git add -A && git commit -m "更新说明" && git push origin main
# 5) 清 EdgeOne 全站缓存（CreatePurgeTask, Type=purge_all）
```

**回滚**：产物仓库 `git revert` 上一提交，或 `git reset --hard <旧 commit>` 后强推，再清缓存。

### 4. 监控与告警

- **关键指标**：HTTPS 证书有效性、站点 200 可达性、EdgeOne 是否回源正常。
- **证书**：EdgeOne 免费证书（eofreecert），`subject=CN = hao.camzy.tech`（TrustAsia DV）；用 `echo | openssl s_client -connect hao.camzy.tech:443 -servername hao.camzy.tech 2>/dev/null | openssl x509 -noout -subject` 核验。
- **日志**：EdgeOne 控制台/CDN 日志；本地构建看 stdout。
- **告警**：证书到期、回源 403、域名被解析篡改需人工复核。

### 5. 数据与存储

- 网页版设置与快捷链接存浏览器 localStorage（无服务端数据库）。
- WebDAV 同步目录：`MiaokeStart`；备份文件：`miaoke-start-backup.json`（设置→其他导出）。
- 无自建数据库/对象存储，迁移 = 重开页面即同步。

### 6. 安全红线

- 密钥/Token 一律用占位符，禁止明文写入仓库、文档、日志。
- 源码改动不推回上游 `Redlnn/lemon-new-tab`，仅产物推 `miaoke-start`。
- 不使用未授权账号改动 DNS/CDN；故障应急联系：Camzy（站内私信）。
