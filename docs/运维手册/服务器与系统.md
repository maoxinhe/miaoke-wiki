## 系统基础操作（通用）

以下为通用命令示例，**需结合实际系统版本核对后再执行**：

| 操作 | 命令示例（通用） |
| --- | --- |
| 查看系统版本 | `cat /etc/os-release` |
| 查看资源占用 | `top` / `free -h` / `df -h` |
| 查看服务状态 | `systemctl status <服务名>` |
| 重启服务 | `systemctl restart <服务名>` |
| 查看监听端口 | `ss -tlnp` |
| 查看磁盘空间 | `df -hT` |
| 查看登录日志 | `journalctl -xe` / `tail -f /var/log/...` |

## 用户与权限规范

- 使用专用账号执行操作，**避免长期使用 root 登录**；需要提权时用 `sudo` 并按最小权限授权。
- 新成员加入：创建账号 → 加入对应组 → 配置 `sudo` 规则（按需）→ 登记。
- 成员离开：及时禁用账号、回收权限、轮换共享密钥。
- 所有授权变更在团队登记表中留痕。
