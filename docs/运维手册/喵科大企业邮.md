# 喵科大企业邮 · 运维知识

> 本文档为「喵科大企业邮」的运维与部署规范。**所有密钥、Token、密码一律使用占位符，真实值存放于私有配置**。

## 一、项目概览

- **项目名称**：喵科大企业邮（`@camzy.tech` 企业域名邮箱）
- **用途**：在 serv00 上自建的企业域名邮箱服务，提供网页端 Webmail、IMAP/SMTP 接入与 SSO 一键登录。
- **技术栈 / 依赖**：
  - 主机：serv00（FreeBSD 14.3，无 root、无 Docker）
  - 邮件后端：serv00 内置 Dovecot（`mail3.serv00.com`）
  - 网页客户端：SnappyMail 2.38.2（PHP 8.3）
  - 域名 / DNS：`camzy.tech`，DNS 托管于腾讯云 DNSPod
  - 证书：腾讯云 TrustAsia（`CN=mail.camzy.tech`）
  - CDN：腾讯云 EdgeOne；SSO 身份源：`sso.camzy.uno`（OIDC）
- **负责人**：猫星河 / 管理员（`admin@camzy.tech`、`postmaster@camzy.tech`）

## 二、运维注意事项

### 1. 运行环境

- **服务器**：`panel3.serv00.com:22`（SSH，用户 CATKINR）；邮件服务器 `mail3.serv00.com`，IMAP 993 / SMTP 465（SSL）。
- **域名**：Webmail 登录 `mail.camzy.tech/login`；官网 `mail.camzy.tech`。
- **关键路径**（均为 serv00 上真实路径）：
  - Web 根：`/usr/home/CATKINR/domains/mail.camzy.tech/public_html/`
  - 登录入口：`public_html/login/index.php`；官网：`public_html/index.html`
  - 数据目录（webroot 外）：`/usr/home/CATKINR/mailapp/data/_data_/_default_/`
  - SSO：`public_html/sso/{login.php,callback.php,btn.js}`
- **密钥清单**（一律存私有配置，禁止明文进文档/代码）：SSH 密码、邮箱账号密码、DNSPod SecretId/SecretKey、sso admin_key、OIDC client_secret、`ssopass.json` 密码库。

### 2. 启动 / 停止

无独立守护进程，全部由 serv00 托管，改文件即时生效。如需重启 Web 服务，用 serv00 面板重启 php-fpm（具体命令待核对，不建议手动作）。

### 3. 部署与发布

- **流程**：本地改文件 → `sftp/scp` 上传 → 源站直连验证：

```bash
curl -sk -H 'Host: mail.camzy.tech' https://128.204.223.70/...
```

- **回滚**：改前备份（如 `index.php.bak_root`），出错即恢复备份文件。
- **发布官网**改根 `index.html`；Webmail 只动 `/login/` 下文件。

### 4. 监控与告警

- **指标**：每账号 1G 用量、磁盘、MX/SPF/DKIM 有效性、证书有效期（现至 2027-01-14）、收发可用性。
- **日志**：serv00 面板查看；PHP 错误看 `public_html` 下错误日志，邮件日志查 mail3。查法以面板日志为准（待核对具体路径）。
- **告警**：证书临期、DNS 记录失效需及时处理。

### 5. 数据与存储

- 邮箱数据由 serv00 托管于 mail3；备份建议用 IMAP 全量拉取，或 serv00 自带备份。
- `ssopass.json`（SSO 密码库）在数据目录旁，须随备份一起保留。

### 6. 安全红线

- 一切密钥/Token 用占位符 `<你的密钥在私有配置>`，严禁明文提交。
- 改 DNS 邮件记录前先存回滚基线（旧 MX/SPF/DKIM）。
- 发布后需在 EdgeOne 控制台刷新缓存。
- serv00 无 root/Docker，禁止强推 Mailcow 等容器化方案。
